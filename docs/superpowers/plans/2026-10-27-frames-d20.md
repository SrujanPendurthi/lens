## Global Constraints

- Everything in D19 that D20 doesn't amend stays fixed: sample, pages, budgets, arms rag/rerank/raw, the answer prompt, models, CPU.
- **Judge system prompt:** the current `JUDGE_SYSTEM`, with this sentence inserted right before `Reply with JSON only:`: `Do not extract statements about the evidence itself (e.g. "the evidence does not say X") as claims.`
- **Judge cache key prefix `frames-judge-v1` becomes `frames-judge-v2`.** The system prompt is not part of the key, so without the bump stale judgments would replay.
- **Lens arm:** `rank("maxsim", question, sentences_of_page, length=64)`, with each sentence scored alone. Packing, adjacency merging and rendering are unchanged.
- **Gate D20**, for C vs B. A question is grounded-correct for an arm if its verdict is `CORRECT` and it has 0 UNSUPPORTED claims.
  - Win = C grounded-correct and B not; loss = the reverse.
  - **PASS** needs all of: `wins − losses ≥ 5`; one-sided sign-test p < 0.05; pooled unsupported rate C ≤ B; median retrieval ms C ≤ 1.25 × B.
  - The fail reasons print in this order: `net`, `significance`, `unsupported`, `speed`.
  - The output lines are `D20 lens vs rag`, `D20 product edge lens vs rerank`, and `reported rerank vs rag`.
- **Claim check:**
  - Agreement on the 30 positives (Sonnet label == `opus_label`) must be ≥ 27/30.
  - At least 9/10 negatives must be labeled UNSUPPORTED.
  - Otherwise STOP before Task 3.

## Review Focus

1. **Stale judge cache:** a v1 judgment must never be reused. Pinned: `test_judge_key_v2`.
2. **A claim the judge splits into several, or drops entirely:** any UNSUPPORTED part makes the claim UNSUPPORTED. Zero extracted claims counts as `NO_CLAIM`, which is a disagreement for positives and a miss for negatives. Pinned: `test_claim_label_rules`.
3. **Grounded-correct on abstentions:** an abstained answer is never grounded-correct. Pinned: `test_d20_gate`.
4. **Speed regression:** the Lens arm must call `rank` once per page with sentences, not windows. Pinned: `test_lens_scores_sentences_once`.
5. **The pooled unsupported guard uses ≤, not <:** equal rates pass. Pinned: `test_d20_gate`.
